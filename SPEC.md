This is parakeet-run it is a golang project that uses the https://github.com/androiddrew/go-parakeet/tree/v0.1.0 for speech to text transcription and provides an OpenAI compatible rest api. It will be a cousin service to https://github.com/androiddrew/kokoro-run which should be referenced for repository architecture, testing, ci, changelog tracking etc. We want to target the same execution environments that are also targeted in kokoro-run. 

Validation just needs to be performed for CPU and CUDA on this development machine. The user will manually build docker images on jetson devices to validate docker builds for those target devices. There is a cuda /opt/onnxruntime/1.22.0-cuda12/lib/libonnxruntime.so and a cpu /opt/onnxruntime/1.22.0-cpu/lib/libonnxruntime.so you can use for verification and testing on this machine.
